# Exported Model Artifacts

This folder holds the trained/quantized outputs of `model/training/train.py`:

- `kalpana_kws.tflite` — quantized (int8) TFLite Micro model, generated by running:
  ```
  cd model/training
  python train.py
  ```
- `kalpana_kws.h` — C byte-array version of the `.tflite` file, for embedding
  directly in firmware (generate with `xxd -i kalpana_kws.tflite > kalpana_kws.h`
  or the TFLite Micro `xxd`-equivalent tooling).

No trained model is checked in yet — this folder is a placeholder until a
real dataset (see `data/README.md`) is available and training has been run.
